# 4. AI 활용 내역

## 4-1. 서비스 안에서 쓰는 AI
| 항목 | 내용 |
|---|---|
| 모델 | Google Gemini `gemini-3.5-flash-lite` (Google AI Studio API) |
| 쓰는 곳 ① | 점주 질문에서 조건 추출(읍면동·예산·오전/오후 인력·바꿀 수 있는 항목). 구조화 출력(JSON 스키마), temperature 0 |
| 쓰는 곳 ② | 리포트 일부 문장(관측·내 가게·원인 후보·추가 확인)을 읽기 쉽게 다듬기. 문장 수·순서·근거 번호는 코드가 고정 |
| 프롬프트 | `src/coach/prompts/extract_slots.md`(조건 추출), `src/coach/prompts/polish_report.md`(문장 다듬기). 코드와 분리해 제출물에 포함 |
| 쓰지 않는 곳 | 숫자 계산, 데이터 적합성 판정, 진단 분류, 실험 선택, 검증은 모두 코드·규칙이 수행 |
| 안전장치 | 지역은 시범 목록 안에서만 선택(밖이면 버리고 되묻기), 음수 등 이상값 제거, 질문에 없는 값은 null → 되묻기. 다듬은 문장도 검증이 숫자를 근거 값과 대조하고 의미 보존 표현을 검사 |
| 장애 대비 | 503·429는 1회 재시도. 그래도 실패하거나 키가 없으면 규칙 기반 추출·템플릿 문장으로 자동 전환 |
| 끄기 | `COACH_LLM=0` (재현·평가 기본값) |

## 4-2. 개발에 쓴 AI 도구
| 도구 | 사용 범위 |
|---|---|
| Claude Code (Anthropic) | A·C 파트: 코드 작성, 테스트, 디버깅, 문서화 |
| Claude (Anthropic) | B 파트: 구현 단계 안내와 코드 작성, 코드 리뷰, 디버깅, PR·문서 초안 |

- AI가 만든 코드는 팀원이 직접 실행·테스트하고 GitHub PR 리뷰를 거쳐 반영했습니다.
- 평가 문항의 정답은 실행 전에 규칙·데이터 사실로 정했고, 평가 결과에 맞춰 임계값·정답을 바꾸지 않았습니다.
- [확인 필요: 팀원별로 쓴 다른 AI 도구]

## 4-3. 외부 API·서비스, 외부 데이터, 외부 코드
- 외부 API·서비스: 제주데이터허브 오픈 API, 공공데이터포털(기상청 ASOS), Google Gemini API, Docker Hub(`python:3.14.10-slim`), GitHub Actions(CI)
- 외부 데이터: 기상청 ASOS 일자료, 행정안전부 행정동코드 (상세는 `02_데이터_활용_명세.md`)
- 오픈소스: `02_데이터_활용_명세.md` 2-5, 전체 목록은 `requirements.lock`
- 외부 코드: 오픈소스 라이브러리 외에 복사해 온 외부 코드는 없습니다.

> 제출 버전: 태그 `v0.2.1` (기능 동결 `v0.2-freeze` + 제출 문서) · 작성일 2026-11-19

## 1-2. 설치·실행 절차

### 방법 ① Docker (권장)
ZIP을 푼 폴더에서:
```powershell
docker build -t jeju-coach .
docker run --rm --network none jeju-coach                     # 재현: 인터넷을 끊고 검증 → 테스트 → 평가 → 데모
docker run --rm -p 8501:8501 jeju-coach python tasks.py app   # 점주용 화면 → 브라우저 http://localhost:8501
```
- LLM 기능까지 켜려면 1-4의 "평가용 LLM 키"를 참고해 `.env`를 만든 뒤 `--env-file .env`를 붙입니다(`.env`는 이미지에 들어가지 않습니다).
  ```powershell
  docker run --rm -p 8501:8501 --env-file .env jeju-coach python tasks.py app
  ```
- 확인한 소요 시간(팀원 PC): 첫 빌드 103~285초, 재현 21~39초, 이미지 약 970MB

### 방법 ② Python 3.14 가상환경 (Docker가 없을 때)
python.org에서 **Python 3.14.x**를 설치한 뒤, ZIP을 푼 폴더에서:
```powershell
python --version                       # 3.14.x 확인
python -m venv .venv
.venv\Scripts\python tasks.py setup     # requirements.lock 기준 설치(버전·해시 검사)
.venv\Scripts\python tasks.py reproduce # 재현
.venv\Scripts\python tasks.py app       # 점주용 화면 → http://localhost:8501
```

## 1-4. 환경변수 (`.env.example` → `.env`로 복사)

| 이름 | `.env.example` 값 | 설명 |
|---|---|---|
| `COACH_MOCK` | `0` | 0: 실제 데이터(스냅샷) / 1: 가짜 지역 지표(개발·테스트용) |
| `COACH_LIVE` | `0` | 1: 라이브 모드(점주 기록 시기에 맞춰 API 조회, 데이터 키 필요) / 0: 기준일 스냅샷 |
| `COACH_LLM` | `0` | 1: LLM으로 조건 추출·리포트 문장 다듬기 / 0: 규칙 기반만 |
| `LLM_PROVIDER` | `gemini` | LLM 제공사 |
| `LLM_API_KEY` | (비움) | Google AI Studio API 키 |
| `LLM_MODEL` | `gemini-3.5-flash-lite` | 모델 이름 |
| `JEJU_DATAHUB_KEY` | (비움) | 제주데이터허브 키(라이브 모드·스냅샷 새로 만들 때만) |
| `DATA_GO_KR_API_KEY` | (비움) | 공공데이터포털 기상청 ASOS 키(라이브 모드·스냅샷 새로 만들 때만) |

값은 따옴표·앞뒤 공백 없이 `이름=값`으로 적습니다. `.env`는 저장소와 제출물에 넣지 않습니다.

### 평가용 LLM 키 (심사용)
- 심사 환경에서도 LLM 기능을 확인할 수 있도록 **평가 전용 Gemini 키**를 아래에 적어 둡니다. 이 키는 결제를 연결하지 않은 **무료 등급 키**라 비용이 발생하지 않습니다.
- 평가 기간(~2026-11-27)이 끝나면 키를 폐기합니다.
- 키가 막히거나 무료 사용량을 넘어도 **규칙 기반 추출로 자동 전환**되어 결과가 나옵니다. 일시 오류(503·429)는 1회 재시도합니다.

```
COACH_LLM=1
LLM_API_KEY=[제출 ZIP에서만 기입]
```
- Docker: 위 두 줄을 `.env`에 넣고 `--env-file .env`를 붙여 실행합니다.
  ```powershell
  docker run --rm -p 8501:8501 --env-file .env jeju-coach python tasks.py app
  ```
- 가상환경: 키는 `.env`의 `LLM_API_KEY`에 넣고, LLM 사용 여부는 **실행할 때 터미널에서** 켭니다. (`tasks.py`는 실행 모드 값을 `.env`가 아니라 터미널 환경에서 읽습니다.)
  ```powershell
  # PowerShell
  $env:COACH_LLM="1"; .venv\Scripts\python tasks.py app
  ```
  ```bat
  :: cmd(명령 프롬프트)
  set COACH_LLM=1 && .venv\Scripts\python tasks.py app
  ```
- LLM이 실제로 쓰였는지는 화면 맨 아래 "처리 과정(심사·개발용)"에서 확인할 수 있습니다. 실패해 규칙 기반으로 넘어가면 결과 아래에 "AI 이해 기능이 잠시 불안정해 기본 방식으로 처리했어요"가 표시됩니다.

## 1-5. 사용자 매뉴얼 (점주용 화면)

화면 순서: **고민 → 가게 정보 → 최근 주문 12주 → 결과**

1. **처음이에요 / 2주 전에 받은 코드가 있어요**
   처음이면 그대로 두고, 2주 전에 실험을 받았다면 오른쪽을 눌러 6자리 코드를 넣습니다.
2. **어떤 점이 고민이세요?** — 편하게 문장으로 적습니다.
   예) "애월에서 카페해요. 요즘 손님이 줄었는데 뭘 해 보면 좋을까요?"
3. **가게 정보** — 눌러서 고릅니다. 모르면 비워 둬도 고민 문장에서 찾아보고, 그래도 없으면 다시 여쭤봅니다.
   - 가게 위치(시범 4곳: 애월읍·노형동·한림읍·연동)
   - 이번 달 실험에 쓸 수 있는 돈, 오전·오후에 일하는 사람 수("직접 입력"으로 다른 값 가능)
   - 바꿔 볼 수 있는 것(메뉴·영업시간·가격·배달·포장·SNS, 여러 개 가능)
4. **최근 주문 수(선택)** — "주문 수 적기"를 펼쳐 12주 주문 수를 적습니다. 날짜는 지역 데이터 기간(2026-08-31까지)에 맞춰 미리 채워져 있습니다. 12주가 있어야 최근 6주와 직전 6주를 동네 흐름과 비교할 수 있습니다.
5. **결과 보기**
   - **지금 우리 가게 상황**: 동네 전체가 함께 줄었는지 / 우리 가게만 줄었는지 / 계절·날씨 영향인지 / 아직 판단하기 어려운지
   - **이번 2주 동안 해 볼 것**: 드는 돈, 추가 인력, 기간, 확인 방법, 그만둘 기준
   - **2주 뒤에 다시 와 주세요**: 재방문 코드(다른 사람에게 알려 주지 마세요)
   - 데이터가 부족하면 맨 위에 "이번엔 일부만 분석했어요"와 이유가 먼저 나옵니다
6. **자세히 보기**: 근거와 원인 후보 / 왜 이 실험인가요 / 받을 수 있는 지원제도 / 한계와 데이터 출처 / 처리 과정(심사·개발용)

**시연용**: 왼쪽 사이드바에서 시연용 가게(합성 점주 데이터)를 고르면 입력이 자동으로 채워집니다. 결과에 "시연용 합성 점주 데이터" 표시가 붙습니다.

## 1-6. 오류·제약사항

### 자주 만나는 상황
| 증상 | 원인과 조치 |
|---|---|
| `tasks.py validate`가 FAIL | 데이터 폴더(`data/snapshot/2026-08-31/`) 위치나 내용이 다름 → ZIP의 폴더를 그대로 넣었는지 확인 |
| 결과 맨 위에 "[판정 불가] 기준일 지역 데이터(스냅샷)가 없어…" | 스냅샷 폴더가 빠짐 → 위와 같음 |
| A 평가에 "건너뜀 1"(A07) | 라이브 동결 데이터(`data/live/snapshots/노형동_2026-06-28/`)가 빠짐 |
| 라이브 모드에서 HTTP 403 | 데이터 키가 틀렸거나 활용 신청이 안 됨(`.env` 값 끝에 공백·`\` 등이 붙지 않았는지 확인). 서버 불안정은 502 |
| LLM 오류(503·429·키 없음) | 자동으로 규칙 기반 추출·템플릿 문장으로 전환, 결과는 정상 |
| "조금만 더 알려 주세요" | 지역·예산·인력 중 빠진 조건이 있거나 시범 지역 밖 → 화면에서 골라 주면 진행 |

### 제약사항
- **데이터 시점**: 제주데이터허브 No.753·748 원천이 2026-08-31에서 멈춰 있어, 그 이후 기간은 라이브로도 채울 수 없습니다. 기간이 맞지 않으면 "가장 최근 동네 흐름만 참고"로 안내합니다(F5·F7).
- **시범 범위**: 업종은 카페, 지역은 애월읍·노형동·한림읍·연동 4곳입니다.
- **라이브 모드**: 데이터 키가 필요하고, 첫 조회는 10~60초 걸립니다(같은 동네·기간은 캐시로 즉시). 실패하면 기준일 스냅샷으로 분석하고 사유를 남깁니다.
- **LLM은 선택**: 꺼져 있어도 모든 흐름이 동작합니다.
- **지역 단위**: 유동인구는 읍면동 전체의 일 합계이며, 매장 방문객·고유 방문자·관광객 수가 아닙니다.
- **정확도**: 평가 수치는 합성 사례 기준이며 실제 점주 대상 정확도가 아닙니다.
